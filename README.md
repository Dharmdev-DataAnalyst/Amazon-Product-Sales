# Amazon-Products-Sales-Analysis-PowerBI

 ## Project Overview

The Amazon Products Sales Analysis Dashboard is an interactive Power BI project designed to analyze sales performance, product trends, and customer reviews.

This project transforms sales data into meaningful business insights using data visualization, KPI analysis, and interactive filtering.

The dashboard helps understand sales trends, product category performance, and top-performing products based on sales and customer reviews.

## Business Objectives

Analyze Year-to-Date (YTD) and Quarter-to-Date (QTD) sales.
Track monthly and weekly sales performance.
Identify the highest-performing product categories.
Analyze top 5 products by YTD sales.
Identify products with the highest customer reviews.
Build an interactive dashboard for business decision-making.
